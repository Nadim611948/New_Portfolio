# MD Nadim Mostofa — Portfolio (Next.js)

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build
```

Deploy: push to GitHub and import the repo on Vercel.

Photo: put your image in `public/` (for example `public/photo.jpg`) and change the hero `<img src=...>` in `app/page.tsx` to `/photo.jpg`.
